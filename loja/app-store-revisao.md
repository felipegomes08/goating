## Privacidade do app (App Store Connect > Privacidade do app)

Coleta dados? Sim. Nenhum dado é usado para rastreamento (tracking = não).
Todos abaixo: vinculados à identidade do usuário, finalidade "Funcionalidade do app".

| Tipo de dado | Item |
|---|---|
| Informações de contato | Nome, Endereço de e-mail |
| Conteúdo do usuário | Fotos (foto de perfil, capa, foto do time), Outro conteúdo do usuário (chat, notas e comentários) |
| Identificadores | ID do usuário |
| Compras | Histórico de compras (assinatura Premium) |
| Identificadores | ID do dispositivo (token de notificação push) |

Não coletados: localização (o GPS só centraliza o mapa no celular, não é salvo), dados de saúde, financeiros, contatos, histórico de navegação, diagnósticos, anúncios.
